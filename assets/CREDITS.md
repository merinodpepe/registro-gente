# Créditos de diseño

El estilo de esta web está basado en dos plantillas del repositorio
[Website-Templates](https://github.com/learning-zone/website-templates) (licencia MIT, © 2024 Dawid Olko):

- **Street Life** (Callum Rimmer, [iFrame](http://www.personal-web-design.com)): imágenes `header.jpg`, `background.jpg`, `camera.gif`, `go.gif`, paleta oscura con acento amarillo y estructura de cabecera/columnas.
- **Photo Art**: fuentes y paleta secundaria (cian y lima).

Fuentes incluidas en `assets/fonts/`:
- *Jenna Sue* — libre para uso personal y comercial (ver `jennasue-LICENSE.txt`).
- *News Cycle* — SIL Open Font License 1.1 (ver `newscycle-OFL.txt`).
